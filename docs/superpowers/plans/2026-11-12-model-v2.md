# Model v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dodać do modelu sześć nowych źródeł informacji (kary na starcie, różnica czasów w kwalifikacjach, pit stopy, tempo wyścigowe vs kwalifikacyjne, zużycie opon, temperatura) oraz uczciwą ocenę poza próbką i kalibrację szans.

**Architecture:** Dla każdego zakończonego wyścigu liczymy raz zestaw agregatów (`RaceAggregates`) i zapisujemy w `public/data/history/`. Nowe czynniki czytają je z `RaceContext.aggregates`. Test wsteczny obejmuje sezony 2022+, a każdy czynnik przechodzi bramkę poza próbką (strojenie na sezonach wcześniejszych, ocena na późniejszym).

**Tech Stack:** bez zmian (Python 3.12, pydantic 2, numpy, httpx, pytest; React 19, vitest).

**Spec:** `docs/superpowers/specs/2026-11-12-model-v2-variables-design.md` (rozszerza `2026-11-12-f1-prediction-app-design.md`)

## Global Constraints

- Koszt 0 zł, tylko darmowe API. Limity: Jolpica ~200 zapytań/h, OpenF1 3/s. Okrążeń i postojów nie pobieramy przy każdym uruchomieniu: liczymy raz na zakończony wyścig (budżet `BACKFILL_RACES_PER_RUN`).
- Czynnik bez danych zwraca `None` (nigdy nie zgadujemy). Brak OpenF1 wyłącza czynniki od niego zależne, nie przerywa przebiegu. Awaria Jolpica przerywa przebieg (pliki nietknięte), jak dotąd.
- OpenF1 ma dane od 2023 (`config.OPENF1_FIRST_SEASON`); dla 2022 pola z OpenF1 są puste.
- Agregat zapisujemy tylko gdy jego źródła są kompletne (`ok`) albo legalnie puste (`missing`); `failed` = nie zapisujemy, spróbujemy przy następnym uruchomieniu. Zapisany plik nigdy nie jest nadpisywany. Zapis atomowy (plik tymczasowy + `os.replace`).
- Zmienna zostaje, gdy `keep_rule` (Zadanie 9) daje `True`. W przeciwnym razie jej waga w `FACTOR_WEIGHTS` = `0.0` i nazwa trafia do `LOCKED_WEIGHTS`; kod zostaje.
- Nowe czynniki mają wagę bazową i granice w `config.py` (dolna granica ≥ 0), polską nazwę w `src/lib/labels.js` i wpis w `factors/registry.py`.
- Testy: `.venv/bin/pytest -q`, `npm test -- --run`. Czas polski, Python 3.12-kompatybilnie.
- Po każdym zadaniu asystent pisze użytkownikowi 3–4 zdania prostym językiem. Commity kończą się `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Wyścig bez danych z kwalifikacji lub OpenF1 (2022, brak sesji) → pola agregatu puste, czynniki `None`, brak NaN. (Zadania 5–7, 15–18)
2. Weekend sprintowy, przerwane lub skrócone kwalifikacje, czerwona flaga (postoje, brak Q3) → luki nie psują liczenia, odstające postoje odrzucone. (Zadania 5, 7)
3. Zespół zmienił skład w trakcie sezonu, debiutant, nowy zespół → neutralna ocena, bez NaN, szanse nadal sumują się do 100%. (Zadania 15–18, 21)
4. Oficjalna siatka ze startem z alei serwisowej, brakującym lub zastępczym kierowcą → pełna siatka bez wyjątku. (Zadanie 13)
5. Backfill przerwany, błąd API w połowie, ponowne uruchomienie → żadnych częściowych plików, brak podwójnego pobierania. (Zadania 7, 11)
